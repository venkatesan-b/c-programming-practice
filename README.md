## Repository Structure
- `basics/` — Beginner programs and fundamental concepts
- `arrays/` — Array-based exercises
- `strings/` — String manipulation exercises
- `leetcode/` — LeetCode solutions written in C

These folders will be expanded as I add relevant programs.

## Current Programs

## How to Run
Compile using GCC:

```bash
gcc hello_world.c -o hello_world
```

Run on macOS or Linux:

```bash
./hello_world
```
